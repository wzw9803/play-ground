# 发明人澄清记录(2026-08-07,来自发明人王鑫)

以下为针对专利工程师问题的关键澄清,用于修正答复文档中 needs-clarification 条目:

## 1. 运行场景形态(对应 7.1.1 Q1、总述 Q1)
- **多种形态都支持**:纯虚拟 3D 场景(浏览器/移动端,数字孪生、虚拟看房)、AR 增强现实、VR 虚拟现实均适用。
- "当前位置、速度、加速度"指**虚拟场景中的相机状态**(旋转/平移/缩放漫游),统一以"相机状态"作为预测模型输入。

## 2. "世界模型"术语(对应总述 Q4)
- **建议修改题目术语**:将"世界模型"改为"**基于用户行为预测的 3D 空间数据协同加载与非线性 LOD 调度方法及系统**",避免与学术界的 World Model 概念混淆。

## 3. 待加载 3D 场景的来源(对应总述 Q3)
- **用户指定/配置场景地址**:用户或应用配置传入 3D Tiles 场景(如 tileset.json 地址),系统加载整个场景的瓦片树元数据,实际空间数据按视锥体 + 预加载策略按需获取。

## 4. 交互场景适用性(对应总述 Q2)
- **交互场景也适用大部分策略**:预测预加载、非线性 LOD、跳级加载均适用交互场景;
- 仅"用后即卸"策略不适用交互场景(因释放 CPU 侧几何数据会破坏射线拾取、编辑等功能),与文档 7.1.4 的限定一致。
